# 电子布洛芬

给有社交需求、又容易被社交耗尽的年轻人做的校园情绪实验。选个接近的状态，画两笔，把心情捏成一只会动的吉祥物。想回应别人的状态时，可以点一个共鸣。

## 本机启动

需要 Node.js 22.16+ 和 Blender。程序会查找系统 PATH、macOS 应用目录及 Steam 的 Blender 安装目录。也可以在 `.env.local` 里用 `BLENDER_PATH` 指定 Blender 可执行文件。

```sh
npm ci
npm run dev
```

打开 [全屏情绪画板](http://127.0.0.1:4173/)，画个轮廓或使用范例，再让吉祥物走进人大校园。也可以直接进入 [校园地图](http://127.0.0.1:4173/#campus) 看看同学留下的话，或者去 [制造间](http://127.0.0.1:4173/#lab) 编排动作。模型生成后，在「服用说明」里点选动作或轻点吉祥物，拖动可以旋转视角。

## 配方与 3D

- 配置密钥后，程序优先使用 Cloudflare 的 Gemini 4 Hydrogen，其次使用 OpenAI 的 GPT-5 mini。未配置密钥时使用本地配方。配置方法是把 `.env.example` 复制为 `.env.local` 并填入所用服务的密钥。也可以在制造间取消勾选「用 AI 解读草图」。
- 身体网格从草图生成。Blender 填充主要闭合轮廓，沿边缘向前后鼓起立体体积，再把表情和可动的手脚装上去。开口草图会用笔迹围成的外形补全，轮廓内部的细节用造型配方和笔迹压印表现。
- 一次生成三个动作。在「编排自己的动作」里，每行可以写一段由至多三步组成的动作，例如「左手挥两下，再跳一下」。可以编排挥手、摇肚、大笑、蹬腿、呼吸、弹跳、转圈、转身、点头和停顿。
- AI 根据草图和状态生成名字、台词和动作编排。四种情绪各有五档表情，拖动烈度滑杆可以预览。情绪改变动作节奏，烈度控制动作幅度，手臂在肩口以外留出活动空间。模型和三段动画都导出到 GLB，配方和 GLB 可以在结果页查看或下载。

## 校园留言墙和展示墙

作品默认只在当前浏览器的匿名会话里可见。可以把状态、吉祥物和台词匿名发布到 [展示墙](http://127.0.0.1:4173/#board)，也可以撤回。不同浏览器会话可以互相点共鸣，热度前三会在制造间轮播。初始的三只吉祥物标为演示样本。

[留言墙](http://127.0.0.1:4173/#messages) 收录公开的校园地点留言，也支持直接写一句。作者可以编辑或收回自己的留言，其他访客可以点「我也在」。

在「校园地图」点选人大校园地点，吉祥物会沿路走过去。进入校园或抵达地点时，它会按之前选的主要情绪自动表演一次。地图默认斜俯视，点「全图」可切换到北向地图。可用滚轮、触屏双指或地图上的加减按钮缩放，拖动地图平移。建筑轮廓、道路和地点来自 OpenStreetMap，建筑高度有估算。地图数据按 [ODbL 1.0](https://www.openstreetmap.org/copyright) 提供。

公开留言可带「赶 DDL」「赶作业」等情境标签。校园热力榜按最近 24 小时内的标签参与人数排列，同一匿名会话对同一标签计一次。点标签可查看对应的留言，也可以只点标签旁的「我也在」。

生成的媒体、发布状态和共鸣保存在服务进程的 `data/`，可通过 `ZZLIGHT_DATA_DIR` 指定持久目录。可用 `npm run mascots` 重做三个内置样本。

## 构建版部署

在安装 Node.js 和 Blender 的主机上执行 `npm ci`、`npm run build`，再由进程管理器运行 `npm start`。Node 同时提供静态页面、生成 API 和模型媒体，监听 `127.0.0.1`，端口由 `PORT` 指定，默认 `4173`。将域名反代到该端口，并在服务主机配置 `.env.local` 和持久数据目录。通过 HTTPS 反代时，将 `ZZLIGHT_PUBLIC_ORIGIN` 设置为浏览器访问的完整站点来源（例如 `https://zzlight.example.com`）。

使用 Ubuntu 软件包安装 Blender 时，同时安装 `python3-numpy`，供 GLB 导出器使用。
